## 三条完整流程

| 流程 | 已验证行为 |
|---|---|
| 背词到正式复习 | 注册/登录→切换词书→修改目标→按剩余出题→答错重测→未通关拒绝结算→通过并防重复结算→次日零点出现复习→重复作答不重复计数→暂停/恢复/掌握/重置 |
| 内容到阅读错词入队 | 模拟AI生成预览→编辑→保存→搜索/文章收藏→保存阅读位置→手动完读防重复→阅读测验后端判分→仅错词入正式复习；TXT实际multipart上传、替换、预览和保存也验证 |
| 数据互通 | 切换词书、重新登录后学习记录、收藏及阅读位置保留；阅读超纲错词可被正式复习抽取；收藏夹/小结自主练习不修改正式记录、阶段、排程或今日复习数量 |

此外覆盖：其他用户不可访问私有文章/草稿/题组；重复和并发生成/保存/结算；版本冲突；事务失败回滚；暂停词不会被阅读错题自动恢复；迟到旧状态请求不会撤销新状态。

## 剩余事项：按必要性排序

1. **前端实现与多端实机联调。** 当前还没有项目业务前端。释义显示开关、错词重测队列的展示顺序、滚动位置恢复、点击定位、按钮禁用和网络重试需实际页面验证；后端测试不能替代UI验收。
2. **确定发音来源。** 需求有播放按钮，后端未提供音频资源或TTS接口。需要选择端侧发音方案或后端音频来源，再补字段/接口；现在不能承诺播放功能已完成。
3. **确认是否需要“全部今日到期词”的独立分页列表。** 当前有due_count及最多10词的正式题组、已暂停词分页，但没有完整到期词分页查询。若复习页只是按组刷题可直接联调；若要展示全部到期词清单，应补专用只读接口。
4. **明确“账号/云同步设置”的具体范围。** 已有注册登录和服务器数据保留，但没有同步开关、离线冲突合并、Token刷新/撤销等专用接口。需求未定义具体交互，不把它们算已交付设置功能。

## 已知限制和部署检查

- 当前仓库词书数据文件只有CET6和考研；未核验生产库是否另有四级数据。接口支持列出/切换已有词书，不能由接口存在推断所有词书内容已经入库。注册依赖基础库存在CET6luan_1。
- TXT最多200KB/40000字符，需手动分章；仅匹配2～12字中文义项，不做语境消歧。同义项多候选按词书顺序选择，须预览检查。
- AI正文标签必须使用词库原词，不支持标签内词形变形；编辑只能保留该草稿目标词，至少一词。真实模型可能输出不合规内容，failed状态必须处理。
- 正式新学/复习在干扰释义池不足时仍有固定兜底释义；自主练习会明确拒绝不足3个有效干扰项。若要求所有题目干扰项都来自真实词库，应另行统一正式出题策略。词义相近导致的语义歧义也需要题库质量验收。
- 累计学习天数由已有活动记录日期并集推算，无法恢复从未留存的历史活动；不是完整不可变学习事件日志。
- 单词收藏toggle会反转状态，不能盲目自动重试；文章收藏和其他使用request_id的修改具备明确幂等语义。前端须按接口类型处理。
- 原建表Markdown已提取为database/schema.sql，重复user_story_records已清理，包含完整外键。后续以迁移文件管理变更；IF NOT EXISTS不会修复已有结构，不重复执行初始脚本来升级现有库。

## 本轮修复

验收时补齐旧入口的输入校验：注册/登录非对象或非字符串参数；单词收藏、目标修改、完读非对象JSON；非法单词/文章ID与收藏来源；词表非法分页和筛选。原先可能出现500或数据库错误，现返回业务400。用户名限制为3～50字符，与数据库字段长度一致；有效请求流程保持原行为。无需新SQL，更新代码后重启即可。
